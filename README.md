# Foxlight Homebrew tap

This is the official Homebrew tap for the Skulk desktop application.

## Install Skulk

```bash
brew install --cask Foxlight-Foundation/skulk/skulk
```

The cask installs the signed and notarized Skulk app for Apple Silicon Macs.
The application includes the coordinated Skulk runtime, so a separate Skulk
installation is not required.

## Upgrade Skulk

```bash
brew upgrade --cask Foxlight-Foundation/skulk/skulk
```

Release artifacts are hosted at
[releases.foxlight.ai](https://releases.foxlight.ai/desktop/macos/latest.json).
